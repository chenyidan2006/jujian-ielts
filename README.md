# 句间 · 雅思观点练习

把观点练成自己的表达。雅思观点库英文跟打、中文回译与错句复习。

纯静态站点（HTML/CSS/JS），无后端、无构建步骤。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 页面入口 |
| `style.css` / `custom.css` | 样式 |
| `app.js` / `custom.js` | 交互逻辑 |
| `data.js` | 句库数据 |
| `translations.js` | 逐句中文译文 |
| `analytics.js` | 匿名统计（无 provider 时自动空转） |

## 部署

直接把本目录作为静态站点根目录即可，无需构建：

- 腾讯 EdgeOne Pages：直接上传本目录，或导入本仓库
- GitHub Pages：Settings → Pages → Source 选 `main` 分支根目录
- Cloudflare Pages / Netlify / Vercel：发布目录填 `.`

## 说明

内容来自个人提供的学习资料，仅供个人练习使用。


## 2026-10-20 学习工具

正式站点：https://chenyidan2006.github.io/jujian-ielts/

- 每句旁边可随手记词义、替换、语法和短语，自动保存在本机，返回该句时默认收起。
- 写作短语本：从顾家北句库核对整理的 50 个表达、6 类用途，附释义、用法与原句出处；支持收藏与自记。
- 段落模板：18 个可改写句型，覆盖开头、两个主体段和结尾；这些句型为另外编写，不是书中原句。
- 移除了原英语问答笔记入口；未清除浏览器里旧模块的数据。
- 学习笔记的导入导出位于新模块中，与原练习进度导出分开。

本项目为静态网站，个人笔记保存在各自浏览器中，不会上传到 GitHub，也不会自动跨设备同步。
